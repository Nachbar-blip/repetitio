# Deck „Klasse 10" Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Repetitio um ein viertes Deck „Klasse 10" mit rund 74 Methodenkarten entlang des
schulinternen Stoffverteilungsplans Mathematik Klasse 10 erweitern.

**Architecture:** Reine Daten- und Verdrahtungsarbeit. Eine neue Deckdatei `data/klasse10.js`
im bestehenden Format `window.REPETITIO_DECKS["klasse10"]`, eine Kachel in `index.html`,
die Deck-ID in der Standardliste von `tests/render_check.py`. Keine Änderung an Engine, CSS
oder `trainer.html`. Das Render-Gate `render_check.py` ist hier der Test: es läuft nach jeder
Kategorie und muss 0 Mängel melden, bevor die nächste Kategorie beginnt.

**Tech Stack:** Statisches HTML/JS, KaTeX (offline unter `vendor/katex/`), Playwright + pytest
für die Gates, Wolfram Language für die Fachprüfung der Rechenbeispiele.

**Design:** `docs/plans/2026-09-19-klasse10-deck-design.md`

## Konventionen für alle Kartentasks

Kartenformat (exakt wie in `data/geometrie.js`):

```js
{
    id: "k10-007", niveau: "ga",
    category: "potenz",
    question: "Wie bestimme ich die Umkehrfunktion einer Wurzelfunktion?",
    answer: `
        <h4>Umkehrfunktion</h4>
        <div class="formula-box">
            $$f(x) = \\sqrt{x} \\quad \\Rightarrow \\quad f^{-1}(x) = x^2,\\; x \\ge 0$$
        </div>
        <p>Vorgehen: nach \\( x \\) umstellen, dann \\( x \\) und \\( y \\) tauschen.</p>
        <details class="example">
            <summary>Beispiel anzeigen</summary>
            <div class="example-content">
                …
            </div>
        </details>
    `
}
```

Regeln, die für jede Karte gelten:

- `niveau` immer `"ga"` (Klasse 10 kennt kein gA/eA; `"ga"` heißt „in beiden Modi sichtbar").
- IDs `k10-001` aufsteigend, lückenlos, niemals nachträglich ändern oder neu vergeben.
- Jeder LaTeX-Backslash im Template-String verdoppelt: `\\frac`, `\\cdot`, `\\(`, `\\sqrt`.
  Ein einfaches `\f` wäre ein Steuerzeichen.
- Formeln in KaTeX-Delimitern: `$$…$$` abgesetzt, `\\(…\\)` im Fließtext.
- Frage immer als Methodenfrage („Wie …?", „Woran erkenne ich …?"), nicht als Aufgabe.
- Jede Karte hat genau einen `<details class="example">`-Block mit einem durchgerechneten
  Zahlenbeispiel.
- Formeln kurz halten: bei 400 px Breite darf nichts über die Karte hinauslaufen. Lange
  Rechnungen auf mehrere `$$…$$`-Zeilen mit `<br>` verteilen statt in eine lange Zeile.
- Zahlenmuster und Aufgabentypen aus dem lokalen Materialindex als Vorlage nehmen,
  adaptiert und umformuliert. **Keine** Quellenmetadaten (Verlag, Buch, Seite, Datei) und
  keine wörtlich übernommenen Verlagspassagen — Repetitio liegt öffentlich auf GitHub Pages.

Gate nach jeder Kategorie:

```
python tests/render_check.py klasse10
```

Erwartet: `klasse10: 0 Mängel` und Exit 0. Bei Mängeln erst beheben, dann committen.

  Wurzelgleichung mit Quadrieren und Probe, Scheinlösungen.
